## Внесённые изменения

### Бэкенд (`server.js`, `.env.example`)

- Конфиг `OPENWEBUI_BASE_URL/API_KEY/MODEL/TIMEOUT_MS`; фича включается только при полном наборе
  (`AI_ANALYSIS_ENABLED`), частичная настройка даёт предупреждение при старте.
- Таблица `ai_analyses` в `ensureTenantSchema` (scope `result|student|group`,
  `target_id` VARCHAR — id результата/студента или имя группы, `UNIQUE(scope, target_id)`,
  MEDIUMTEXT `content`). Хранится только последний анализ; перегенерация — UPSERT.
  При `DELETE /api/results/:id` анализ результата удаляется.
- `callLlm(messages)` — нативный `fetch` на `{base}/api/chat/completions`, `stream:false`,
  `temperature:0.3`, `AbortSignal.timeout`. Ошибки: 503 «не настроен», 504 таймаут, 502 недоступен/пусто.
- Обезличивание: `buildScoredSummary(row)` строит сводку через `scoreMethodology`
  (шкалы: имя/балл/макс/уровень/метка/attention + предупреждения достоверности).
  **ФИО/логины/контакты в промпт не попадают** — закреплено юнит-тестами. В групповом промпте
  студенты подписаны «Студент 1..N», соответствие номеров реальным студентам не сохраняется;
  лимит 50 студентов с пометкой об усечении.
- Промпты: общая константа `AI_PROMPT_COMMON` (роль ассистента педагога-психолога, только переданные
  данные, структура ответа, оговорка «не диагноз») + билдеры `buildResultPrompt/buildStudentPrompt/buildGroupPrompt`.
- Роуты (`authenticateToken, requireStaff`): `GET /api/ai/status`,
  `GET /api/ai/analysis?scope=&targetId=` (кэш, 200 с `null`), `POST /api/ai/analysis` (генерация).
  Куратор скоупится на свою группу (чужой result/student → 404, чужая группа → 403);
  только `completed`-результаты; параллельная генерация одной цели → 429; аудит `AI_ANALYZE`.
- CSP не менялась: все вызовы LLM серверные, ключ API в браузер не попадает.

## Известные ограничения и риски

1. `style-src 'unsafe-inline'` в CSP — прежнее ограничение, не связано с этой сессией.
2. Пароль MySQL короче 12 символов — прежний риск, плановая замена.
3. Переименование группы «осиротит» её групповой анализ (ключ — имя группы);
   приемлемо: анализ перегенерируется по кнопке.
4. Кэш анализа не инвалидируется автоматически при появлении новых результатов —
   психолог видит дату формирования и может нажать «Обновить».
5. Ответственность за качество текста несёт внешняя модель; в системный промпт и UI/PDF
   зашита оговорка «не диагноз, выводы делает специалист».
