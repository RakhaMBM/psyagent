# Межагентная передача контекста

Последнее обновление: 2026-06-27

## Цель сессии

Продолжить ближайший автономно выполнимый пункт плана: устранить выполнение inline-JavaScript,
ужесточить CSP и подтвердить отсутствие функциональных и визуальных регрессий.

## Текущее состояние

- `main` содержит изменение CSP `0657910` (`Harden CSP against inline scripts`) и этот
  документационный коммит; локальная ветка опережает `origin/main` на два коммита.
- Push заблокирован: remote использует HTTPS, GitHub CLI не установлен, сохранённых HTTPS-учётных
  данных и SSH deploy key на сервере нет.
- Production-процесс `psyagent` перезапущен и работает online.
- `http://127.0.0.1:3000/` возвращает HTTP 200 и новый заголовок CSP.
- Рабочие методики, мультиарендность, отчёты и интеграционный сценарий остаются исправны.
- Изменений схемы БД и данных не выполнялось.

## Внесённые изменения

### CSP и frontend

- Из `script-src` удалён `'unsafe-inline'`; добавлено `script-src-attr 'none'`.
- Inline-скрипты пяти страниц вынесены в `public/index.js`, `admin.js`, `student.js`,
  `curator.js`, `platform.js`.
- 77 inline-обработчиков (`onclick`, `onchange`, `oninput`) заменены атрибутами `data-action`.
- Добавлен `public/event-actions.js`: единый делегированный диспетчер `click`, `change`, `input`,
  поддерживающий JSON-аргументы, передачу события/элемента/значения и безопасные служебные действия.
- Исправлена навигация администратора: `showSection` теперь получает инициирующий элемент явно,
  без неявной зависимости от глобального `event`.

### Тесты и документация

- Security-тесты переведены на новые page-JS.
- Добавлены регрессии, запрещающие inline-скрипты и обработчики в HTML и динамических шаблонах,
  а также возврат `'unsafe-inline'` в `script-src`.
- `AGENTS.md` и `CLAUDE.md` обновлены под структуру HTML + page-JS и делегирование событий.

## Известные ограничения и риски

1. `style-src` всё ещё содержит `'unsafe-inline'`: Bootstrap, Chart.js, существующие style-атрибуты
   и печатные представления используют inline-стили. Исполняемый JavaScript уже закрыт строгой CSP;
   удаление inline-стилей требует отдельной совместимой миграции и браузерного прогона.
2. Пароль MySQL остаётся короче рекомендуемых 12 символов. Текущий production запускается благодаря
   legacy-совместимости, но пароль нужно планово заменить одновременно во всех потребителях и `.env`.
3. В `tmp/pdfs/` могут оставаться игнорируемые PNG визуальной сверки PDF; в Git они не входят.
4. Единый browser-to-database e2e не автоматизирован: REST проверяется MySQL integration-тестом,
   UI — Playwright с mock API.

## Отложенные продуктовые решения

- Анонимные анкеты 1.2.3/1.2.4 требуют отдельного неперсонального модуля.
- Методика Кожухарь для педагогов требует режима респондента-сотрудника.
- Методика Ракишевой не автоматизируется до получения исправленного официального ключа.
- Тарифы/подписка, лендинг/демо/триал и согласия ПДн отложены владельцем.

## Следующий рекомендуемый шаг

1. Установить GitHub CLI и выполнить `gh auth login` либо добавить отдельный SSH deploy key
   репозитория с write-доступом; затем отправить `main` в `origin`.
2. Планово усилить пароль MySQL с проверкой всех потребителей и безопасным обновлением `.env`.
3. После отдельного решения владельца выбрать следующий продуктовый модуль:
   анонимные опросы либо диагностику сотрудников.
4. При дальнейшей работе с CSP вынести inline-стили с учётом Bootstrap/Chart.js и печатных окон.
