## Внесённые изменения

### Управление колледжами и пользователями

- Для активного колледжа в `/platform` одновременно доступны «Отключить» и «Удалить»;
  для отключённого — «Включить» и «Удалить». Колледж `default` остаётся защищённым.
- Секция сброса пароля заменена управлением пользователями выбранного колледжа:
  поиск, фильтры по роли/статусу, создание, редактирование, включение, отключение
  и смена пароля только для отмеченных строк.
- Роль существующего пользователя не меняется при редактировании, чтобы не нарушать
  связанные данные. Нельзя отключить последнего активного психолога колледжа.
- Психолог может отметить конкретных студентов или кураторов и изменить им пароль
  либо отключить их. Новый `/api/users/bulk` ограничен `req.db` и ролями
  `student|curator`, поэтому другие психологи недоступны.
- Супер-администратор работает через БД выбранного tenant; добавлены CRUD и bulk API
  `/api/platform/tenants/:id/users...`.
- Модуль диагностики сотрудников не изменялся и не должен начинаться без отдельного указания.

### Анонимные опросы

- Добавлены визуально сверенные по официальному сборнику анкеты 1.2.3 и 1.2.4.
- Кампании создаются психологом и получают случайную публичную ссылку `/survey/:college/:token`.
- `anonymous_responses` не содержит `user_id`, ФИО, логина или IP; доступен только
  агрегированный отчёт по вариантам ответа.
- Реализованы создание, копирование ссылки, закрытие/повторное открытие, сводка и удаление кампании.

### Колледжи, пароли и доступ студента

- В `/platform` доступны как временное отключение колледжа, так и безвозвратное удаление
  с вводом точного кода и повторным подтверждением. `default`, основная БД и БД вне
  разрешённого префикса защищены.
- Добавлена команда `npm run reset-student-passwords` и режим `--verify-only`.
- Новые студенты без явного пароля получают настроенный `DEFAULT_STUDENT_PASSWORD`.
- Студент больше не получает `methodology_data`, веса вариантов, API методик или балл после
  завершения; UI показывает только факт завершения и сообщает, что результат доступен психологу.

### PDF

- Печать браузера заменена прямым скачиванием PDF через pdfmake.
- Реализованы PDF по студенту, отдельному результату, группе и колледжу; кабинет куратора
  также скачивает PDF студента.
- PDF поддерживает кириллицу, многостраничные таблицы, шкалы, риск, динамику и подпись.

## Известные ограничения и риски

1. `style-src` всё ещё содержит `'unsafe-inline'`: Bootstrap, Chart.js и существующие
   style-атрибуты используют inline-стили. Исполняемый JavaScript уже закрыт строгой CSP;
   удаление inline-стилей требует отдельной совместимой миграции и браузерного прогона.
2. Пароль MySQL остаётся короче рекомендуемых 12 символов. Текущий production запускается благодаря
   legacy-совместимости, но пароль нужно планово заменить одновременно во всех потребителях и `.env`.
3. Единый browser-to-database e2e не автоматизирован: REST проверяется MySQL integration-тестом,
   UI — Playwright с mock API.
4. Публичная анонимная ссылка не может технически запретить повторную отправку без идентификации;
   интерфейс ставит локальную отметку в браузере, сервер сознательно не создаёт идентификатор респондента.

## Отложенные продуктовые решения

- Методика Кожухарь для педагогов требует режима респондента-сотрудника; не начинать
  этот модуль без отдельного указания владельца.
- Методика Ракишевой не автоматизируется до получения исправленного официального ключа.
- Тарифы/подписка, лендинг/демо/триал и согласия ПДн отложены владельцем.
